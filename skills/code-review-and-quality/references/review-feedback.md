# Review feedback

1. Read the full comment and surrounding diff.
2. Restate the technical request without its social framing.
3. Verify the premise against code, tests, contracts, and project conventions.
4. If sound, implement the smallest complete change and verify it.
5. If unclear, ask one precise question before broadening scope.
6. If unsound, explain the conflict with concrete evidence and offer a compatible alternative.

Avoid reflexive agreement, defensive argument, partial fixes that ignore the stated concern, and unrelated cleanup.
