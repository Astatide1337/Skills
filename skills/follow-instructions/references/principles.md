# Decision principles

Use this index when a decision needs more guidance. Read the relevant reference;
the short task path does not require it. Use the owning skill for the procedure
and verify the result before claiming completion.

| Choice | Reference |
| --- | --- |
| Scope or new moving parts | [outcome and scope](principles/outcome-and-scope.md) |
| State, interfaces, types, or ownership | [ownership and domain](principles/ownership-and-domain.md) |
| Unnecessary layers or unclear flow | [simplicity and reader load](principles/simplicity-and-reader-load.md) |
| Unclear cause or disputed behavior | [cause and behavior](principles/cause-and-behavior.md) |
| Migration, retries, or shared writers | [safe evolution](principles/safe-evolution.md) |
| User/maintainer trade-off | [experience and communication](principles/experience-and-communication.md) |
| Repeated work or delegation | [leverage and verifiable units](principles/leverage-and-verifiable-units.md) |
| Repeated failed premise | [challenge and adapt](principles/challenge-and-adapt.md) |
| Authority or completion claim | [authority and claims](principles/authority-and-claims.md) |
