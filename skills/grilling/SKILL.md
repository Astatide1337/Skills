# Grilling

Ask one consequential question at a time. Follow each answer into its weakest assumption rather than marching through a generic checklist.

Cover, as relevant: intended outcome, users, constraints, ownership, data model, failure modes, security, operability, migration, rollback, cost, and what is deliberately excluded. When an answer depends on a fact, inspect the available evidence with read-only tools; delegate only when the environment permits and it is genuinely useful.

Do not start implementing. Keep a compact decision log of confirmed decisions, unresolved risks, and assumptions that need evidence. Stop when the plan is coherent enough to execute or the user asks to stop. End with the decisions, remaining unknowns, and the first concrete next step.
