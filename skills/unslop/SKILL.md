# Unslop

Preserve facts, decisions, uncertainty, citations, and necessary nuance. Remove throat-clearing, repetition, fake quotations, canned headings, self-congratulation, vague intensifiers, excessive hedging, and previews of points immediately stated afterward.

Prefer concrete nouns and verbs. Name the mechanism. Keep one term per concept. Split clauses when a sentence carries several ideas. Use lists only when the items are genuinely parallel. Do not flatten a useful explanation into terse fragments or erase calibrated uncertainty.

Return the revised text. Add a note only when the source is ambiguous or a requested cut would change meaning.
